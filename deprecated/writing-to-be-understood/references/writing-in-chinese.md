# 写中文时

写中文时，人称代词默认不写。不写「你」「我」「他」之后，读的人仍须立刻知道这句话里做事的是谁。如果省掉人称代词会让读的人去猜这句话的主语是谁，就把做事的人写出来。

必须写出称呼时，写当时对方的身份，不写「你」。写称呼时用的身份，以当时在跟你说话的人为准，也以对方让你说给谁听为准。不要把某一种身份写成全文都固定使用的称呼。

中文句子里，同一个东西既可以用英文名词来叫、也可以用中文来叫时，用读的人平常怎么叫它的那个名字。不要为了少写英文，把它译成读的人不这么叫的中文。也不要为了显得专业，在读的人平常说中文的地方改用英文。有公认、读的人一看就知道的中文叫法，就用那个中文。读的人平常就用英文名词来叫的，就保留那个英文名词。拿不准时，用这个东西在这句话里已经在用的那个名字，不要另换一个。不要为哪些必须用英文、哪些必须用中文列一张词表。

中文和拉丁字母、阿拉伯数字写在同一句里时，中文与拉丁字母之间留一个空格，中文与阿拉伯数字之间也留一个空格。数字和后面的单位之间通常也留一个空格。百分号、角度这类已经成习惯的写法不加空格。全角标点前后不额外留空格。代码、路径和命令内部按它们自己的写法。

```text
使用 Git 管理 3 个仓库。
超时时间为 200 ms，CPU 使用率为 95%。
```

中文句子用全角标点。整句英文和代码用半角标点。中文里的括号一般用全角。括号里主要是英文、版本号或代码时，可以用半角括号。

```text
请运行安装命令（详见下方说明）。
该项目基于 Spring Boot (v3.2.0) 开发。
```
