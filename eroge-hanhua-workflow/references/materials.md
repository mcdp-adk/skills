# 工作材料与流程衔接

首次安排工作目录时查[目录职责](#目录职责)；准备代表样本或新增来源时查[从资源到翻译材料](#从资源到翻译材料)；回填、构建或修订译文时查[从译文到游戏资源](#从译文到游戏资源)；恢复与交接查[维护与交接](#维护与交接)。这里约定材料用途和环节衔接，具体格式与工具由目标游戏决定。

## 目录职责

用户确认工作目录与交付目录后，工作目录内部默认按下表安排。已有项目沿用能承担相同职责的位置，记录入口即可；路径名称不决定授权。交付目录只承载准备交给用户的内容，测试和未完成材料留在工作目录。

| 默认位置 | 用途与边界 |
| --- | --- |
| `source/` | 原版的提取材料及来源定位；作为只读参考，能对应指定原版版本。原版无需移入工作目录，也不要求完整复制或解包 |
| `translation/` | 当前译文及翻译、审校状态；按需要提供上下文引用。引擎原生本地化文件适用时可直接作为维护格式 |
| `assets/` | 用户提供或制作所需的字体等材料、来源与许可；原版提取资源仍归来源材料 |
| `tools/` | 实际使用的提取、适配、回填与构建工具，或可重复操作的说明 |
| `build/` | 从维护材料生成的中间结果和候选补丁；手改结果需回到相应维护来源修正 |
| `test/` | 测试游戏副本、测试数据和验证记录；运行数据的具体放置按[数据保护](verification.md#测试环境与用户数据保护)决定 |
| `records/` | 当前进度、作品术语表、复盘及必要的处理依据；项目已有记录位置优先 |

按实际需要建立目录，材料少时不强制拆出空目录。开始写入前检查已有内容，工作目录不能把原版或受保护目录包含为可写材料；工作与交付即使存在包含关系，也应区分生成、测试和交付操作的目标，避免清理或打包时串入其他材料。

## 从资源到翻译材料

先识别**语言内容**与**运行数据**：前者传达剧情、人物表达或操作信息，后者承担执行控制、资源定位或状态标识。共用字符串时查清依赖再处理。扩展名和日文扫描只是线索，不单独决定翻译范围。

按纳入内容及判义需要读取或提取资源，保留原文件、内部位置或标识以及必要的使用关系。图片可以提供界面和剧情上下文，字体服务于显示适配；需要时提取或建立可访问的定位。现成工具顺带导出的资源可保留，其他材料随实际需要补充，不要求先将全部资源分类、转换或建立关联。图片提取与查看不自动扩大图片重绘范围。

翻译材料应使执行者无需先理解拆包和构建实现，就能完成以下工作：

- 定位当前内容对应的原文、译文及处理状态，区分未译、已译和已审。
- 查阅相邻剧情、说话人、所属界面或使用条件；不确定时能沿出处补查相关脚本、图片等原始依据。
- 识别必须保留的变量、标签和控制信息，把修改写回确定的译文维护位置。

已有本地化格式满足这些需要时直接使用。否则采用简单表格、结构化文件或适合项目的文本格式；需要补充的上下文可用定位与引用，不复制全部资源进每批材料。上下文未知就标明待查，不把推测写成确定设定。翻译单元与批次的划分见[批次与上下文](translation.md#批次与上下文)。

## 从译文到游戏资源

**译文基准**是当前完整译文及其处理状态的唯一维护来源，可以由多个分工明确的文件组成。**来源对应关系**使每项译文能够应用到正确的原文位置或引擎本地化标识；它可以由现成格式承载，无需另建一份映射表。

同一原文在不同语境可能有不同译法，按实际位置、上下文或稳定标识区分；只有确认适用范围一致时才共享译文。动态表达还需保留变量身份、组合条件和回填方式。位置随重新提取变化时，先核对对应原文，不能把旧译文按新行号直接写入。

回填与构建读取译文基准，生成目标脚本、资源或补丁；引擎适配逻辑负责格式与控制结构。生成脚本中出现中文是正常结果，但语言修正应回到译文基准，不能只留在生成脚本或构建工具的字面常量中。中文显示依赖的字形或图片等派生结果，也从对应维护来源更新。

原版、译文或必要资源变化后，重新生成受影响结果并检查来源匹配、覆盖、格式和引用。未知来源、冲突映射及回填失败应明确报出并停止依赖操作，不能靠静默跳过、错位替换或无说明地回退原文来宣称成功。未纳入范围或阶段性未译内容的保留规则应明确。

可重复手工步骤、小型脚本和引擎已有导入机制均可使用，选择能服务当前及已明确后续工作的方法。先验证实际输入到实际结果的链路；不为未来可能的引擎建设通用转换平台。重建和同类变化的验证要求见[样本方法的适用范围](verification.md#样本方法的适用范围)。

## 维护与交接

| 材料 | 维护内容 |
| --- | --- |
| 原文基准 | 指定版本的原文、资源及可查回的使用关系；提取物保留来源，不当作已译成果 |
| 译文基准 | 当前译文与处理状态；确认、修订后更新受影响的生成结果 |
| 作品术语表 | 人物名、专名和需统一的称谓，区分候选与定译；规则见[作品术语表](terminology.md#作品术语表) |
| 当前进度 | 两个目录及已有位置对应、当前阶段、覆盖情况、待办、阻塞、执行步骤和证据入口 |
| 复盘 | 新发现、原因、修正、实际验证范围及未解决项；计划与已完成结果分开记录 |

以上是材料职责，不要求各自新建一种文件。沿用现有记录入口，避免同时维护多份进度或术语表。交接指向实际材料，完整正文与逐项修正留在文件，摘要帮助定位而不替代原文与验证依据。
