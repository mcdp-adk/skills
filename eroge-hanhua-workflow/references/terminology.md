# 易错术语辨义

遇到非常用词、特殊用法或容易混淆的关系时，按下列主题查询。本参考提供辨义线索和出处，中文候选仍需结合作品判断。作品条目、别名及定译的维护见 [作品术语](translation.md#作品术语)。

## 先确定当前用法

分别确认词义、指代对象和表达强度。同一个词可以用于普通生活、成人场景或游戏机制；出现在 eroge 中并不意味着每次都是成人义。作品证据决定它这一次指什么，辞书用于核对可能义项，中文表达再按当前语域选择。

医学名、日常词、幼儿语、委婉词和粗俗词可能指向相关对象，但不能直接互换。知道具体部位，不代表应把含糊台词补写成器官名；常见中文惯译也不能替代对动作方向、人物关系或语法的判断。

## 语法与人物关系

| 难点 | 判断与容易造成的错误 |
| --- | --- |
| 授受表达 | 对 `てあげる／てくれる／てもらう` 先还原施事、受益方和视点。说话人可以站在他人一侧叙述，不能见词形就补成固定的“我”和“你” |
| 使役、受身与使役受身 | 先确定谁使谁做什么、谁受影响。使役可以涉及强迫或许可等关系，具体态度和同意程度须有语境依据 |
| `義兄／義姉` | 沿配偶、兄弟姐妹等亲属关系确认中文称谓，也可能涉及结义；不能按汉字默认“义兄姐”，重组家庭关系也须查作品事实 |
| 姓名、职称与匿名称呼 | 同一对象可以有不同叫法，同一职称也可指不同人。保留当时的身份披露程度，不能用后文真名替换早期未知姓名 |
| 敬称与口吻线索 | 后缀、自称和敬语提供关系或语气信息；人物身份、性别和情绪不能仅凭其中一个词形确定。中文可通过称谓和整句表现差异 |

授受见 [国際交流基金的说明](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/grammar/201409.html)；使役的语法意义见 [早津恵美子的研究](https://www.jstage.jst.go.jp/article/gengo/148/0/148_143/_article/-char/ja/)，使役受身见 [国際交流基金教材](https://www.kyozai.jpf.go.jp/kyozai/material/BMA00076/ja/render.do)。亲属义项见小学馆辞书的 [義兄](https://kotobank.jp/word/%E7%BE%A9%E5%85%84-473096) 与 [義姉](https://kotobank.jp/word/%E7%BE%A9%E5%A7%89-473470) 条目；辞书枚举不替代作品内亲属链。

## 身体与生殖用语

| 难点 | 判断与容易造成的错误 |
| --- | --- |
| `外陰部／膣・腟／膣口` | 区分外部区域、通道和开口。模糊俗称或指示词不必提升为精确解剖名称 |
| `穴／あそこ` 等泛指 | 相邻动作、选项和条件帮助确定所指；原文仍是委婉或概括表达时，中文保留相应明确程度 |
| `子種` | 辞书含精子及孩子等义，不能固定替换为“精液”。具体台词是否保留生育隐喻，要看表达意图 |
| 身体反应、动作与结果 | 分开判断原文究竟描述感受、行为、状态还是结果；不能因其中一项出现，就补写另一项已发生 |

部位区别可查 [MSD 日文说明](https://www.msdmanuals.com/ja-jp/home/22-%E5%A5%B3%E6%80%A7%E3%81%AE%E5%81%A5%E5%BA%B7%E4%B8%8A%E3%81%AE%E5%95%8F%E9%A1%8C/%E5%A5%B3%E6%80%A7%E3%81%AE%E7%94%9F%E6%AE%96%E5%99%A8%E7%B3%BB%E3%81%AE%E7%94%9F%E7%89%A9%E5%AD%A6/%E5%A5%B3%E6%80%A7%E3%81%AE%E5%A4%96%E6%80%A7%E5%99%A8)；这些概念资料不规定角色台词语域。`子種` 见 [集英社《広辞典》](https://imidas.jp/kojiten/detail/W-10-1-623-06.html)。

## 俗称与表达强度

| 日文 | 判断与容易造成的错误 |
| --- | --- |
| `おっぱい` | 辞书含乳汁、乳房义并标幼儿语；成人台词中的亲昵、玩笑或粗俗程度仍由当前口吻决定，不能一律译成医学名或幼儿腔 |
| `まんこ` | 辞书释为女性性器的俗称；它不是精确部位标识，“俗称”也不能直接换算成最强烈的中文粗俗表达 |

以上义项见小学馆辞书的 [おっぱい](https://kotobank.jp/word/%E3%81%8A%E3%81%A4%E3%81%B1%E3%81%84-3208847) 与 [まんこ](https://kotobank.jp/word/%E3%81%BE%E3%82%93%E3%81%93-687594)。具体中文是结合语境作出的选择，保留原文有意设置的表达差异。其他身体俗称同样先查所指与语域，不以同一对象为由统一全篇用词。

## 动作、状态与机制

| 日文 | 判断与容易造成的错误 |
| --- | --- |
| `しゃぶる` | 辞书说明含在口中吮弄等动作，词本身不确定是否成人用法、动作对象或参与者，不能统一替换成一种行为名 |
| `素股` | 具有腿部相关普通义与成人动作义；成人用法也不能误写成插入行为 |
| `いく・イく` | 可为移动、进展、辅助表达，特定成人语境中可指达到高潮；高潮义不自动等于射精或其他结果 |
| `いかせる` | 除当前义项外还需判断使役方向，不能把“使对方……”改成说话人自身的状态 |
| `開発` 等作品机制用语 | 先查搭配对象、状态变化和具体机制；普通义与题材引申义分别判断，没有可靠依据时不设通用中文定译 |

动作义项可查集英社的 [しゃぶる](https://imidas.jp/kojiten/detail/W-12-1-640-06.html)，以及小学馆辞书的 [素股](https://kotobank.jp/word/%E7%B4%A0%E8%82%A1-543465) 和 [行く](https://kotobank.jp/word/%E8%A1%8C%E3%81%8F-431393)。`開発` 的成人引申义在本参考中不提供统一释义，遇到时以作品语境查证。

## 行业、类型与复合表达

| 难点 | 判断与容易造成的错误 |
| --- | --- |
| `風俗` 及复合词 | 同时存在生活习俗和风俗店等相关义；查完整搭配、场所与活动，不能一律译成民俗，也不能扩写成某种具体成人服务 |
| `攻め／受け` 等类型角色 | 类型角色与人物性格、当前行为分别判断，不能据标签补出强势、被动或某种具体行为已经发生 |
| `タチ／ネコ` | 核对作品的社群与关系语境，区分类别用法和普通字面义；不能把某一社群的解释当作所有作品的统一定义 |

类型标签用于归类，其信息不等于某句台词或某个场景的完整关系。翻译正文时仍核对人物、行为和叙事视点，不从标签推断原文没有表达的动机、同意关系或心理状态。

缩略语和复合词连同修饰对象一起查，先确定它指动作、道具、身份还是机制；熟悉其中一个词根不足以决定全词。拟声和声音表达也要区分身体反应、情绪和实际声响，保留原有节奏与强度，不把所有声音统一成同一种表达。

行业义见小学馆辞书的 [風俗](https://kotobank.jp/word/%E9%A2%A8%E4%BF%97-124870)，`タチ` 的条目所列女性同性关系用法见 [精選版 日本国語大辞典](https://kotobank.jp/word/%E3%81%9F%E3%81%A1-2059598)；其他用法仍需另查。类型惯例与角色多样化可参考 [堀あきこ的 BL 研究综述，第 52 页](https://www.jstage.jst.go.jp/article/genderhistory/20/0/20_47/_pdf/-char/en)，不能把特定研究对象的归纳直接套到所有 eroge。

## 表外词的查证

先沿作品原文、调用或场景确认对象和用法，再查相应辞书、语料或专业资料。出版社辞书帮助辨认义项和语域，语法资料帮助判断关系，医学资料只用于区分概念；社区用法可以提供检索线索，不能直接替代原文依据。

将实际结论写回作品术语材料，未查证的候选与采用译法分开。没有必要穷尽整个题材的词汇；本参考未收录不表示该词可以跳过，翻译中重要的疑义仍需查清。
