# 中文用词

统一中文交流中的写法，只收录需要明确选择的词。项目已有约定时，以项目约定为准；项目概念的定义见其词汇表。

| English | 推荐写法 | 说明 |
| --- | --- | --- |
| issue | issue | 指 GitHub 等平台上的记录；泛指软件问题时直接写“问题”。 |
| triage | triage | 保留英文，如“先做 triage”。 |
| spec | spec | 保留英文，如“编写 spec”“按 spec 实现”。 |
| ticket | ticket | 需要中文时用“工单”。 |
| commit | commit | 指记录时用 commit，如“这个 commit”；指操作时用“提交”，如“提交改动”。 |
| pull request / PR | PR | 如“创建 PR”“评审 PR”“合并 PR”。 |
