# 中文混排

让读者看到的文字排版一致。用户或项目已有明确体例时沿用；整理现有内容时保留原意、措辞和结构。

| 场景 | 写法 |
| --- | --- |
| 汉字与拉丁字母、阿拉伯数字相邻 | 留一个半角空格，如 `用 Python 处理 8 个文件`。专名内部保持原样。 |
| 数值与单位符号 | 按 SI 写法留空格，如 `10 km`、`35 °C`、`8 %`；平面角写 `45°`。有领域规范时遵循该规范。 |
| 中文标点 | 中文句子使用全角标点和括号，标点两侧不另加空格；英文片段内部使用英文标点。 |
| 字符形式 | 正文使用半角拉丁字母和阿拉伯数字；保留专名的正式写法。 |
| 引号与书名号 | 新写大陆简体中文时使用 `“”`，内层使用 `‘’`；书名使用 `《》`。 |
| 省略号与破折号 | 中文正文使用 `……` 和 `——`；区间连接符、负号按各自含义书写。 |

## Markdown

按最终显示的文字决定间距；加粗、链接和行内代码的语法标记不算文字。需要的空格放在标记外，如 `打开**设置**页面`。

Markdown 强调可能在中文标点旁解析失败。新写内容采用能正确渲染的句式和强调范围，如 `**注意**：先备份`；编辑现有内容时保留原有强调对象。

整理文档时，只调整确定会显示的自然语言。保留代码、命令、路径、链接地址、标识符、配置值、嵌入语法和承担结构作用的空白；逐字引用、日志与字符示例保持原样。修改 Markdown 后检查渲染结果，修改标题或引用式链接时检查相关锚点和引用。
