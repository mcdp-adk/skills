# 中文术语

将日语 eroge 翻译为中文时，用本文件辨析反复出现的语义区别。示例使用简体中文，只提供结合语境选用的候选表达，不是自动替换表。先确定所指、义项、语体和场景功能，再使用项目已确定的译法。将采用的译法及例外记录在项目中；仅在缺少合适记录时使用[语言决策模板](../assets/language-decisions.md)。

## 含义与语体

| 日语 | 需要保留的区别 | 中文处理候选 |
| --- | --- | --- |
| おっぱい／乳房 | 日常亲昵称呼与解剖名称不同；おっぱい也可指乳汁 | 按所指与人物口吻选择“胸、乳房、奶” |
| おちんちん／ちんこ／陰茎 | 亲昵、粗俗与医学语体不同 | “鸡鸡”和“阴茎”适合不同口吻；需要时选择直白程度相当的口语表达 |
| まんこ／おまんこ | 俗语可能笼统指生殖器；委婉译法会减弱直白程度 | 保留场景中的具体程度与语体，不把“私处”作为通用译法 |
| 外陰部／膣・腟／膣口／陰核 | 外部区域、内部管道、开口与特定结构 | 外阴／阴道／阴道口／阴蒂 |
| あそこ／穴／中 | 指示性称呼、开口与相对位置 | 那里、下面／洞、洞口／里面；仅根据上下文确定具体所指 |
| 愛撫／前戯／自慰 | 抚摸、性行为前的活动、自我刺激或自我安慰 | 爱抚、抚摸／前戏／自慰；适用时保留非性含义 |
| 舐める／しゃぶる | 舔与吸吮不同；舐める也可表示轻视 | 舔／含着吸吮；なめるな可译为“别小看我” |
| フェラ／クンニ | 区分解剖目标，不直接说明实施者身份 | 结合语境选用“口交／舔阴”；并列标签需要区分时保留区别 |
| 手コキ／パイズリ／素股 | 动作不同，词语本身不说明实施者 | 手交／乳交／股交可作标签候选；素股不表示插入 |
| 行く・イく／射精 | 移动或高潮，与精液排出事件不同 | 根据当前义项选择“去、走”或“高潮”，并与“射精”区分 |
| 中出し／外出し | 区分射出位置，不自动说明后果 | 内射／外射；保留内外区别，不补出怀孕或未说明的具体位置 |
| 精液／精子／子種 | 体液、生殖细胞、比喻或后代 | 按用法选择精液／精子／种、种子、孩子、后代 |
| 受精／受胎／孕む・孕ませる | 受精、受孕、怀孕及使其发生 | 受精／受孕／怀孕、使……怀孕；孕む也有比喻义 |
| 勃起／発情／愛液／潮吹き | 不同状态或现象，不自动表明意愿或同意 | 保留原文描述的状态，不补入同意、诊断或体液成分方面的断言 |
| 喘ぐ／呻く／嬌声／吐息 | 气喘、用力或痛苦时的声音、娇媚声音与呼气 | 喘息／低哼、呻吟／娇声／气息、轻叹；叹气或呻吟不必然表示愉悦 |

词典用于确定可能的含义和语体，不能决定每个场景中的中文措辞。可参考小学馆词条：[おっぱい](https://kotobank.jp/word/おつぱい-3208847)、[おちんちん](https://kotobank.jp/word/おちんちん-453013)、[おまんこ](https://kotobank.jp/word/おまんこ-454419)、[自慰](https://kotobank.jp/word/自慰-76691)、[舐める](https://kotobank.jp/word/嘗める-589904)、[素股](https://kotobank.jp/word/素股-543465)、[孕む](https://kotobank.jp/word/孕む-605122)，以及集英社的[子種](https://imidas.jp/kojiten/detail/W-10-1-623-06.html)。医学定义仅用于区分[外部解剖结构](https://www.kentcht.nhs.uk/leaflet/vulva-care/)、[阴道](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/vagina)与[精液](https://www.cancer.gov/publications/dictionaries/cancer-terms/def/semen)，不规定台词语体。

## 人物关系与虚构设定

| 日语 | 需要从上下文确定的内容 |
| --- | --- |
| 義兄／義姉／お兄ちゃん | 先确定实际关系：姻亲、重组家庭、收养、结义，或非字面的称呼。按关系选择中文亲属称谓，不能只看字面。 |
| 先生／先輩／～様／～ちゃん | 确定身份、地位、亲密程度、反讽和说话人的用法。礼貌也可由整句话表达，不一定对应固定后缀。 |
| 純愛／寝取り／寝取られ／寝取らせ | 保留主动、被动与使役视角。类型标签不能决定每个人物是否同意，也不能概括整条路线的事件。 |
| 凌辱・陵辱／調教／～堕ち | 区分侵犯、训练或支配，以及立场或状态的变化；具体机制由原作决定。 |
| 催眠／洗脳／媚薬 | 区分诱导状态、改变认知与设定中增强欲望的物质。记忆、服从、感情和持续时间以作品设定为准。 |
| 男の娘／ふたなり／TS／女体化 | 区分外在呈现、身体结构、身份与变身。“伪娘、扶她、性转、女体化”属于需结合语境使用的类型用语，不能互换。 |
| 百合／BL／攻め・受け／タチ・ネコ | 类型或配对标签不能决定每个场景中的行为和人物性格；普通词语仍可能使用日常义项。 |
| 風俗／本番 | 区分风俗习惯与成人服务语境，以及正式演出与性交俗语。结合句子和场景判断。 |
| サキュバス／淫紋／開発・性感帯 | 物种、印记、过程和身体区域属于不同概念。“魅魔、淫纹、开发、性感带”需符合原作的定义与效果。 |

词典义项可辅助区分[義兄](https://kotobank.jp/word/義兄-473096)、[寝取る](https://kotobank.jp/word/寝取る-595447)和[調教](https://kotobank.jp/word/調教-568274)。虚构规则和宣传分类仍需作品内的证据；词表不能补出缺失的剧情事实。

## 游戏功能

| 日语 | 功能区别与中文候选 |
| --- | --- |
| 回想／バックログ・履歴 | 场景重放与已显示文本的历史记录：场景回放、回想／文字历史、历史记录 |
| CGモード／差分 | 图库与图像变体：CG 鉴赏／差分、变体图；差分也可能使用数据处理义项 |
| 既読／未読／既読スキップ／強制スキップ | 玩家阅读状态与跳过规则：按实际功能选用已读、未读、跳过已读文本、全部跳过 |
| オート／クイックセーブ／クイックロード | 自动功能可能指阅读、存档、战斗等，需结合语境；快速存档与快速读档是相反的操作 |
| 好感度／服従度／淫乱度／開発度 | 区分关系、服从、欲望或经验，以及开发程度等数值；单位、上限和效果以游戏为准 |
| ルート／選択肢／エンド・ED／回収 | 路线、选项、结局或片尾、收集或解锁、伏笔回收；不把攻略中提前揭示的信息带入台词 |
| 攻略／攻略対象／フラグ | 可能指攻略或策略、恋爱对象、程序状态，也可能是人物有意使用套路梗；按说话人当前语境选择 |

确定界面标签前，检查实际画面或使用该文本的脚本。共享术语的定义与各处用例分别记录；同一写法含有无关义项时保留例外。将这些区别应用到完整表达的方法见[中文表达适配](chinese-adaptation.md)。
