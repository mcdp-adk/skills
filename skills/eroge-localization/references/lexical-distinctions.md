# Lexical Distinctions

Use these reusable semantic contrasts when interpreting Japanese eroge. Chinese examples are contextual candidates, not automatic replacements. Choose the referent, sense, register, and scene function before using a title's established term. Record adopted forms and exceptions with the title, using [language decisions](../assets/language-decisions.md) only if needed.
