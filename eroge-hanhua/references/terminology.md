# 术语辨义

本参考供日文 R18 游戏汉化时查词义、语域和易混点。按需要查[界面与活动](#界面与活动)、[人物与称谓](#人物与称谓)、[身体与生殖](#身体与生殖)、[动作与状态](#动作与状态)或[类型用语](#类型用语)。表内中文均为候选；作品采用的译法由项目术语表记录。

## 如何使用

先从原文查对象、搭配、人物关系和用途。指代藏在数组、条件或动作对象中时，沿使用关系查证。确定含义后，再按人物口吻选择中文：医学名、日常词、委婉词和粗俗词可以指向同一对象，表达强度却不同。

辞书用于核对义项与语域，语料用于查看搭配，医学资料用于区分身体概念，译者和社区资料用于了解习惯表达及争议。下列来源各自支持日语释义、概念或用法，中文候选是编写者的翻译判断。作品证据决定当前指代，社区惯用法供比较。[NINJAL 查证指引](https://www.ninjal.ac.jp/utility/contact/how-to-search/)可帮助选择后续查证材料；使用 [UniDic](https://clrd.ninjal.ac.jp/unidic/en/about_unidic_en.html)识别词形时，翻译单元仍按完整表达划分。

## 界面与活动

同一个词在导航、数值机制和剧情中可能承担不同作用。先确认当前功能，再选择标签或句子需要的词形；短文本方法见[短文本](translation.md#短文本)。

| 日文 | 中文候选与辨义 |
| --- | --- |
| セーブ／ロード | 游戏中常用“存档／读档”，一般数据操作可用“保存／读取”。`ロード中` 还可能是资源加载，须查对象 |
| 設定／コンフィグ | 界面常用“设置”；剧情里的 `設定` 可能是人物或世界“设定” |
| 選択肢／次へ／戻る | 可用“选项／下一步／返回”，分别对应分支、推进和导航。“返回”涉及的取消或保存行为另查，译文按原标签的信息量表达 |
| スキップ／既読スキップ／オート | “跳过／跳过已读／自动”。核对跳过范围与自动推进的区别，“已读”指已读文本 |
| バックログ／回想／鑑賞／おまけ | 可用“文本回顾／剧情回顾／鉴赏／附加内容”。先分清历史文本、剧情重播、图片音频浏览和其他内容 |
| 続きから／はじめから | 常用“继续游戏／开始游戏”。选档、自动续玩及新周目的具体机制由游戏决定 |
| 強くてニューゲーム | 可考虑“强化新游戏”“继承开局”等命名；通常涉及带着已有成长重新开始，具体继承项目须查游戏 |
| 解放／開放／解除 | 根据对象选“解锁／开放／解除”，分别检查内容可用、区域开放及限制解除等含义 |
| 達成／獲得／入手 | “达成／获得／取得”等；完成条件与拿到物品用不同搭配 |
| 好感度／親密度／理性 | “好感度／亲密度／理性”可能各为独立状态量，分别保留其机制含义 |
| ライブ／配信 | `ライブ` 可指现场演出；`配信` 可指直播、播出或内容分发。查看活动、媒介和动作后选词 |
| 芸能活動／イベント | 前者可用“演艺活动”；后者按用途译“活动”或“事件”，程序事件和演出活动有别 |
| スキンシップ／お触り | 可选“肌肤接触／身体接触／触摸／抚摸”。动作性质和亲昵程度依据场景 |
| 洗いっこ／一緒に入る／くつろぐ | 可选“互相帮洗／一起进入或一起泡澡／放松”。核对省略的地点，保留互相与共同的参与关系 |
| 口説く／肩もみ／抱きしめる | 按语境用“劝说或追求／揉肩／拥抱”，区分意图、部位和动作 |
| 技あり／しごでき／モデル級 | “有一手／能干／模特级”等可作候选。查看完整称号，判断技巧评价、网络缩略语和程度表达应怎样组合 |

上述是用途判断与中文候选。[Ren'Py 翻译文档](https://www.renpy.org/doc/html/translation.html)展示了该引擎用上下文区分同形字符串的方法，可供处理同词异用时参考。

## 人物与称谓

核对姓名的原文表记、读音、姓与名的边界，再决定简体字形或音译。人物身份与称谓分开理解：同一人可因说话人、场合而有多个称呼，一个称谓也可能指不同人。匿名、职业及编号标签保留剧情当前披露的信息。

| 日文 | 中文候选与辨义 |
| --- | --- |
| 私／僕／俺／あたし／わし | 通常可用“我”，口吻差异也可通过整句表达。自称提供人物线索，性别和年龄需结合设定确认 |
| 君／お前／あなた | 根据亲疏、礼貌及上下位关系选“你／您”等；`あなた` 也可能是伴侣称呼 |
| ちゃん／くん／さん／様 | 通过姓名、称谓、后缀或句式表达亲昵与敬意。`さん` 需按对象选择，`ちゃん` 是否保留音译取决于作品风格 |
| 先輩／後輩／先生 | 可用“前辈／后辈”，按实际身份选“老师／医生／先生”等。“前后辈”首先描述经历或组织关系 |
| お兄ちゃん／兄貴／お姉ちゃん／姉貴 | “哥哥／大哥／姐姐／大姐”等；先分清亲属、年长同伴和角色化称呼。“大哥”等中文还可能带特定社会口吻 |
| 義兄／義姉 | 沿亲属链选姐夫、嫂子、配偶的兄姐或义兄姐等。辞书含姻亲与结义义项；若作品有再婚家庭设定，核实后再判断继兄姐等译法 |
| 幼馴染／幼なじみ | “儿时玩伴／青梅竹马”等；核对中文候选带来的恋爱暗示是否适合实际关系 |
| 同棲／同居 | “同居／共同居住”等；分清共同生活和未婚伴侣生活的语境。家庭、婚姻状态及标题双关从作品确认 |
| 彼氏／彼女 | `彼氏` 常为“男朋友”，`彼女` 可为“女朋友”或“她”；通过句法与上下文辨认关系名词和代词 |
| 旦那／奥さん／ご主人様 | 可选“丈夫／太太／主人”等，需分家庭、商店、雇佣或侍奉场合。`ご主人様` 与“主人公”是不同概念 |
| マネージャー／マネちゃん／社長 | 按行业选“经纪人／经理”等；昵称保留与正式身份的对应，`社長` 按组织语境用“社长／负责人”等 |
| お客さん／観客／関係者／嬢 | “客人／观众／相关人员／小姐”等。相关人员的范围、称谓的行业意味都须查当前场合 |
| 呼び名／本名／偽名／表示名 | “称呼／本名／假名／显示名”，分别描述称呼、身份及显示用途。玩家输入的名字另与程序内部 ID 区分 |
| 女子A／？？？等标签 | 按实际身份选择“女性 A”等表述，保留匿名、编号或未知状态；此时即使译者知道真名，也应遵循剧情的揭示安排 |

[《義兄》](https://kotobank.jp/word/%E7%BE%A9%E5%85%84-473096)、[《義姉》](https://kotobank.jp/word/%E7%BE%A9%E5%A7%89-473470)支持姻亲与结义义项；继亲关系另需作品证据。[小学馆《同棲》对译条目](https://kotobank.jp/jeword/%E5%90%8C%E6%A3%B2)列出共同生活与未婚男女同居的用法。[文化庁《敬語の指針》](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/kokugo/kokugo_33/pdf/siryou_2.pdf)适合核对关系、场合与敬意的表达。

## 身体与生殖

以下作中性词义说明。先辨认对象，再选符合原文语域的说法；精确解剖名适用于明确的部位，委婉指代则保留其含蓄程度。

| 日文 | 中文候选与辨义 |
| --- | --- |
| 性器／外陰部／膣・腟／膣口 | “生殖器／外阴／阴道／阴道口”，依次区分总称、外部区域、通道和开口 |
| クリトリス／乳首 | “阴蒂／乳头”，均为明确部位；根据原文的表达强度使用 |
| 陰茎／亀頭／陰嚢／精巣 | “阴茎／龟头／阴囊／睾丸”，各指不同器官或部位 |
| アナル／肛門／尻・お尻 | 按语境用“肛门／臀部／屁股”等。`尻` 还有末尾义，`アナル` 复合词要连同修饰对象理解 |
| 股／股ぐら／お股／腰 | 可选“胯部／裆部／腰”等，依据姿势和动作辨认位置。经英语部位词转译时，复核日语的腰、臀、股区别 |
| すじ／マンすじ | 普通义可为筋、线或纹路；特定身体语境中可考虑“阴缝”等。修饰语和对象决定此处是否为成人用法 |
| 穴／あそこ／そこ | “洞／孔／那里／那一处”等。相邻选项、条件和动作可帮助定位；概括一组部位与指向单个器官要分清 |
| おっぱい | “乳汁／胸／乳房／奶子”等。辞书含乳汁、乳房义并标幼儿语，成人对白中的亲昵或粗俗程度须看人物 |
| ちんこ／ちんぽ・ちんぼ | “小鸡鸡／阴茎／鸡巴”等语境候选，幼稚、中性、粗俗程度差异大。日语的幼儿语或俗称标注不能直接确定中文强度 |
| まんこ／おまんこ | “阴部／阴户／屄”等语境候选，属于日语俗称。词义解释和角色对白可采用不同语域；它本身也非精确解剖术语 |
| 精子／卵子／精液 | “精子／卵子／精液”，区分生殖细胞与体液。遇到转喻时结合整句辨义 |
| 子種 | 辞书含精子、后代等义，可选相应词或保留生育隐喻；当前指代需查上下文 |
| 愛液 | “润滑液／阴道分泌液／淫液”等候选语域不同。成人文本的体液称呼并不说明精确生理来源 |
| 月経／生理／排卵／受精／妊娠・孕む | “月经／经期／排卵／受精／怀孕”等，区分阶段及正式、日常语体。`生理`、`孕む` 的其他普通义或比喻义另判 |
| 避妊／コンドーム／性感染症 | “避孕／安全套或避孕套／性传播感染”，区分目的、器具和感染概念；知识说明沿用相应正式语体 |
| 童貞／処女／初体験／初夜 | 描述人物时可用“处男／处女”，其余按语境选“童贞／初次经历／新婚之夜”等。性经历、身份自述与时间名称分别判断，“初次”的对象从上下文确认 |

身体概念可核对 [MSD 男性生殖器资料](https://www.msdmanuals.com/ja-jp/home/21-%E7%94%B7%E6%80%A7%E3%81%AE%E5%81%A5%E5%BA%B7%E4%B8%8A%E3%81%AE%E5%95%8F%E9%A1%8C/%E7%94%B7%E6%80%A7%E3%81%AE%E7%94%9F%E6%AE%96%E5%99%A8%E7%B3%BB%E3%81%AE%E7%94%9F%E7%89%A9%E5%AD%A6/%E7%94%B7%E6%80%A7%E3%81%AE%E7%94%9F%E6%AE%96%E5%99%A8%E3%81%AE%E5%83%8D%E3%81%8D)、[日本产科妇人科学会《HUMAN+》](https://www.jsog.or.jp/public/human_plus_dictionary/book.pdf)和[厚生劳动省性感染症资料](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/kenkou/kekkaku-kansenshou/seikansenshou/)。这些医学资料用于辨认概念，角色对白的语域另依原文。

俗称和多义可查辞书的[おっぱい](https://kotobank.jp/word/%E3%81%8A%E3%81%A4%E3%81%B1%E3%81%84-3208847)、[ちんこ](https://kotobank.jp/word/%E3%81%A1%E3%82%93%E3%81%93-569921)、[ちんぼ](https://kotobank.jp/word/%E3%81%A1%E3%82%93%E3%81%BC-570102)、[まんこ](https://kotobank.jp/word/%E3%81%BE%E3%82%93%E3%81%93-687594)、[尻](https://kotobank.jp/word/%E5%B0%BB-188410)、[穴](https://kotobank.jp/word/%E7%A9%B4-426051)及集英社的[子種](https://imidas.jp/kojiten/detail/W-10-1-623-06.html)。它们支持日语释义，表中的中文强度仍需逐处选择。

## 动作与状态

同一表面词可能表示普通动作、成人行为或游戏机制。连看施事、对象和条件，尤其注意动作方向、阶段及结果是否为原文明说。

| 日文 | 中文候选与辨义 |
| --- | --- |
| キス／愛撫／前戯／挿入 | “亲吻／爱抚／前戏／插入”，分别判断动作和阶段；插入对象由上下文确定 |
| 正常位／騎乗位／後背位・バック | 可用“正常位或传教士式／骑乘位／后背位或后入式”，区分正面相对、跨坐及从后方的姿势。`バック` 另有返回、后方义；`正上位` 等作品表记须查说明或画面后确定 |
| 素股 | 辞书含内腿等普通义和成人行为义。后者可考虑“素股／股间摩擦”，与插入行为有别；菜单和说明文字可采用不同详略 |
| しゃぶる／しゃぶりつく／舐める | “含吮／吮吸／舔”等，依据宾语、动作方式和持续感选择；`舐める` 也有轻视义 |
| オナニー／自慰／手こき | 前两者可用“自慰”，手部刺激可按语境用“手交”等。核对施事与对象，区分自我行为和两人互动 |
| フェラ・フェラチオ／クンニ・クンニリングス | “口交／舔阴”等，前者指向男性生殖器，后者指向女性生殖器。并列菜单需保留对象差别，施事身份另查 |
| 中出し／外出し | “内射或体内射精／体外射精”，描述位置与动作对象；怀孕等后续结果须有原文依据 |
| 種付け | 普通繁殖义可用“配种／授精”；成人材料可能借作“播种”等隐喻，需判断对象、态度与隐喻强度 |
| ローター／バイブ／アナルビーズ | 道具语境可考虑“震动器／跳蛋／按摩棒／肛珠”等，按物品图像和说明对应形态。`ローター` 的普通辞书义为转子等，词形本身不足以判断成人道具外形 |
| ゆっくり動く／激しく動く／ピストン | “缓慢动作／剧烈动作／往复运动”等是辨义候选。放入按钮或正文时，用符合该处动作与语法的中文 |
| 勃起／射精／絶頂／オルガズム | “勃起／射精／高潮”，区分状态、排出过程和感受。`絶頂` 也可为一般巅峰，各现象是否同时发生须看原文 |
| 潮吹き／潮を吹く | 成人语境可用“潮吹／喷液”等，普通语境也可能指喷水。与高潮、射精分别理解，词语本身不确定液体成分 |
| いく・イく／いかせる | 普通义可为去、到，成人用法可为达到高潮及让某人达到高潮。核对使役方向；表记是线索，义项由语境决定 |
| 性欲／精力／エロ技 | “性欲／精力／性技巧”等，欲望、体力和能力可能为独立属性，按机制分别处理 |
| 喘ぎ声 | “喘息声／呻吟声”等，查呼吸、疲劳、痛苦或性语境。拟声与文字说明分别选择表达，强度遵循原文 |
| 開発／調教／射精管理 | “开发／训练／调教／射精控制”等为候选，先区分普通义、引申义与机制名。关系、同意程度和具体行为从作品查证 |

动作义可查集英社的[しゃぶる](https://imidas.jp/kojiten/detail/W-12-1-640-06.html)及辞书的[前戯](https://kotobank.jp/word/%E5%89%8D%E6%88%AF-1691675)、[行く](https://kotobank.jp/word/%E8%A1%8C%E3%81%8F-431393)、[手扱き](https://kotobank.jp/word/%E6%89%8B%E6%89%B1%E3%81%8D-2132894)、[自慰](https://kotobank.jp/word/%E8%87%AA%E6%85%B0-76691)。[正常位](https://kotobank.jp/word/%E6%AD%A3%E5%B8%B8%E4%BD%8D-1691611)、[騎乗位](https://kotobank.jp/word/%E9%A8%8E%E4%B9%97%E4%BD%8D-1690489)、[素股](https://kotobank.jp/word/%E7%B4%A0%E8%82%A1-543465)提供体位或行为释义；[種付け](https://kotobank.jp/word/%E7%A8%AE%E4%BB%98%E3%81%91-562063)、[ローター](https://kotobank.jp/word/%E3%82%8D%E3%83%BC%E3%81%9F%E3%83%BC-3220910)可核对普通义。

译者整理的[体位词表](https://japanesesexterms.com/2023/03/06/20-words-for-sex-positions-in-japanese/)、[射精相关词表](https://japanesesexterms.com/2024/12/05/100-words-for-ejaculation-and-semen-in-japanese/)、[道具词表](https://japanesesexterms.com/2024/12/24/japanese-words-for-sex-toys/)补充成人材料中的缩略语和比喻用法；[高潮相关词表](https://japanesesexterms.com/2024/11/19/100-words-for-orgasm-in-japanese/)收录 `イカせる`、`潮吹き` 等词形。其分类用于查用法，生理概念仍分别判断。口腔性行为的对象区别可核对[日本中四国艾滋病中心术语表](https://www.aids-chushi.or.jp/word/yougo_ver4.pdf)。
