# 术语辨义

这里收录可反复用到的词义差别、中文候选和误译风险。按需要查[界面与活动](#界面与活动)、[人物与称谓](#人物与称谓)、[身体与生殖](#身体与生殖)、[动作与状态](#动作与状态)或[类型用语](#类型用语)。候选由编写者整理；日语来源支持义项或用法，不表示它们是官方中译。作品定译由项目术语表维护。

## 用证据选择译法

先查作品中的对象、人物关系、搭配和显示用途。有时指代还要沿数组、条件或动作对象查证，但查明对象不等于要在译文中明说：原文委婉时保留其含蓄，原文明确时也不任意弱化。

辞书帮助辨认义项和语域；语料帮助看搭配及使用场合；医学资料用于区分身体概念；译者或社区资料提供惯用表达与争议。它们各有所长，不能用社区常见说法覆盖原文，也不能以医学词替代角色的口语。[NINJAL 查证指引](https://www.ninjal.ac.jp/utility/contact/how-to-search/)介绍辞书、语料与论文的用途；[UniDic](https://clrd.ninjal.ac.jp/unidic/en/about_unidic_en.html)可辅助词形识别，其分词单位不直接等于翻译单元。

## 界面与活动

本节是功能判断与中文工作候选，实际功能须从当前游戏查明。

| 日文 | 中文候选 | 含义、语域与易混点 |
| --- | --- | --- |
| セーブ／ロード | 存档／读档；保存／读取 | 游戏操作与一般数据操作可选不同搭配；`ロード中` 要分清读档还是加载资源 |
| 設定／コンフィグ | 设置 | 菜单常用语；叙事里的 `設定` 也可指设定，不能跨用途替换 |
| 選択肢／次へ／戻る | 选项／下一步／返回 | 分支、推进和导航用途不同；“返回”是否取消未保存内容，要查行为，不能自行增添承诺 |
| スキップ／既読スキップ／オート | 跳过／跳过已读／自动 | 区分跳过范围与自动推进，不把“已读”写成“已通关” |
| バックログ／回想／鑑賞／おまけ | 文本回顾／剧情回顾／鉴赏／附加内容 | 分别查看历史文本、剧情重播、图片音频浏览或其他内容；功能不同不必强行统一菜单名 |
| 続きから／はじめから | 继续游戏／开始游戏 | 查选档、自动续玩和新周目的区别；常见标签本身未说明具体机制 |
| 強くてニューゲーム | 强化新游戏／继承开局等 | 通常涉及带着既有成长重新开始；实际继承哪些内容由游戏决定，不能只凭标签添加奖励说明 |
| 解放／開放／解除 | 解锁／开放／解除 | 分清内容可用、区域开放和限制解除；含同一汉字不代表同一机制 |
| 達成／獲得／入手 | 达成／获得／取得 | 完成条件与拿到物品不同，连同提示对象一起译 |
| 好感度／親密度／理性 | 好感度／亲密度／理性 | 可能是独立状态量；保留项目实际概念，不因中文近义合并 |
| ライブ／配信 | 演出／直播／播出／分发 | `ライブ` 可指现场演出，`配信` 也可指内容分发；看活动、媒介与动作，不能一律写成直播 |
| 芸能活動／イベント | 演艺活动／活动／事件 | 前者指演艺工作；后者在程序或剧情中常为事件，在演出场合才可能是活动 |
| スキンシップ／お触り | 肌肤接触／身体接触／触摸／抚摸 | 接触的性质、动作对象与语气由场景限定，不自动升级为性行为名称 |
| 洗いっこ／一緒に入る／くつろぐ | 互相帮洗／一起进入或一起泡澡／放松 | 保留互相、共同等关系；省略的地点先查明，不能将浴室中的所有选项都译成洗澡 |
| 口説く／肩もみ／抱きしめる | 劝说或追求／揉肩／拥抱 | 看动作对象与意图；这些互动不应因题材相同而合并为同一个亲密动作 |
| 技あり／しごでき／モデル級 | 有一手／能干／模特级等 | 称号、网络缩略语和程度表达需看整体命名；独立属性与动态称号可能需要不同词形 |

短文本的组合与审校方法见[翻译与审校方法](translation.md)。[Ren'Py 翻译文档](https://www.renpy.org/doc/html/translation.html)提供用上下文区分同形界面字符串的例子；它证明该引擎的一种解决方式，不为上表中文或其他引擎的格式背书。

## 人物与称谓

| 日文 | 中文候选 | 含义、语域与易混点 |
| --- | --- | --- |
| 私／僕／俺／あたし／わし | 我；按人物口吻表达差异 | 自称带身份与语气线索，但不能单独证明性别或年龄；中文不必逐词配一个特殊自称 |
| 君／お前／あなた | 你／您等 | 可表达亲近、礼貌、上下位或敌意；`あなた` 还可能是伴侣称呼，不固定套“您” |
| ちゃん／くん／さん／様 | 姓名、称谓、后缀或句式补偿 | 亲昵与敬意没有一一对应的中文词；`さん` 不总是先生，`ちゃん` 不必都保留“酱” |
| 先輩／後輩／先生 | 前辈／后辈；老师／医生／先生 | 前后辈主要是经历或组织关系；先生可能为职业称谓或敬称，先核实身份 |
| お兄ちゃん／兄貴／お姉ちゃん／姉貴 | 哥哥／大哥／姐姐／大姐 | 可为亲属，也可为年长同伴或角色化称呼；“大哥”在中文中可能多出江湖口吻 |
| 義兄／義姉 | 按亲属链选姐夫、嫂子、配偶的兄姐或义兄姐等 | 辞书义含姻亲与结义关系。若作品另有再婚家庭设定，先核实再选择继兄姐等说法；不要仅凭字面定亲属关系 |
| 幼馴染／幼なじみ | 儿时玩伴／青梅竹马 | 共同成长不必然意味着恋爱；中文候选应避免额外暗示关系 |
| 同棲／同居 | 同居／共同居住 | 共同居住与未婚伴侣共同生活的用法需分清；家庭关系、婚姻状态和标题双关由作品确认 |
| 彼氏／彼女 | 男朋友；女朋友／她 | `彼女` 的关系名词义与代词义由句法和上下文区分 |
| 旦那／奥さん／ご主人様 | 丈夫／太太／主人等 | 家庭、商店、雇佣或侍奉语境不同；不能把 `ご主人様` 当“主人公” |
| マネージャー／マネちゃん／社長 | 经纪人或经理／昵称／社长或负责人 | 看行业及职位；昵称仍要能对应同一人，不能只统一正式姓名 |
| お客さん／観客／関係者／嬢 | 客人／观众／相关人员／小姐等 | 称谓范围与行业相关；`関係者` 不必全是工作人员，`嬢` 也不自动等于某种职业 |
| 呼び名／本名／偽名／表示名 | 称呼／本名／假名／显示名 | 区分叙事身份、公开称呼和程序显示；玩家输入值不等于内部 ID |
| 女子A／？？？等标签 | 女性 A／？？？等 | 匿名与未知身份本身可能传递剧情信息，不能提前用已知姓名替换；职业及编号也纳入人物指代管理 |

核对姓名时，先查原文写法、读音、姓与名的边界及别名指向，再决定简体字形或音译。配角和匿名称谓同样需要登记；语域不同可以保留多种称呼，但要知道它们指向谁。

[《義兄》](https://kotobank.jp/word/%E7%BE%A9%E5%85%84-473096)和[《義姉》](https://kotobank.jp/word/%E7%BE%A9%E5%A7%89-473470)直接支持上表所说的多种姻亲、结义关系，不直接支持所有继亲用法。[文化庁《敬語の指針》](https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/kokugo/kokugo_33/pdf/siryou_2.pdf)帮助判断关系与场合，不能代替作品家谱或角色设定。

[小学馆《同棲》对译条目](https://kotobank.jp/jeword/%E5%90%8C%E6%A3%B2)区分共同生活与未婚男女同居的用法；它支持辨义，不为某个标题追加婚姻设定。

## 身体与生殖

以下为中性辨义。医学名称、俗称和委婉指代即使涉及同一对象，也不能无条件互换。

| 日文 | 中文候选 | 含义、语域与易混点 |
| --- | --- | --- |
| 性器／外陰部／膣・腟／膣口 | 生殖器／外阴／阴道／阴道口 | 总称、外部区域、体内通道与开口不同；不能因中文自然度把它们合并 |
| クリトリス／乳首 | 阴蒂／乳头 | 明确部位名；不要改成含糊的“那里”，也不要将亲吻等动作列成身体部位 |
| 陰茎／亀頭／陰嚢／精巣 | 阴茎／龟头／阴囊／睾丸 | 区分器官及其部位；正式说明和对白可有语域差异，概念仍需准确 |
| アナル／肛門／尻・お尻 | 肛门／臀部／屁股等 | `アナル` 的复合词还要看修饰对象；`尻` 有臀部及末尾等义，不能一律当肛门 |
| 股／股ぐら／お股／腰 | 胯部／裆部／腰等 | 普通部位词可能用于成人场景，仍要按姿势与动作辨义；经英语 hip 等词转译容易混淆腰臀 |
| すじ／マンすじ | 筋、线、纹路；特定语境中的阴缝等 | 普通 `すじ` 多义，身体指向依赖修饰语和对象；不能把所有出现位置替换成生殖器名称 |
| 穴／あそこ／そこ | 洞、孔；那里、那一处等 | 身体指向可能由相邻选项、条件或动作确认；一组部位的概括也不等于某一个器官。保留原文的概括或委婉程度 |
| おっぱい | 乳汁／胸／乳房／奶子等 | 辞书同时有乳汁、乳房义并标注幼儿语；成人口语的亲昵或粗俗程度另看人物，不凭题材固定译法 |
| ちんこ／ちんぽ・ちんぼ | 小鸡鸡／阴茎／鸡巴等语境候选 | 日语辞书有幼儿语或俗称说明，成人对白中的强度并非固定。中文候选的幼稚、中性、粗俗程度相差很大，不能随意互换 |
| まんこ／おまんこ | 阴部／阴户／屄等语境候选 | 日语俗称，不等同精确解剖名；中性解释与粗俗对白要区分，也不能把明确俗称一概改成“那里” |
| 精子／卵子／精液 | 精子／卵子／精液 | 生殖细胞与体液不同；原文若有非医学的转喻用法，结合整句理解，不反向改写概念 |
| 子種 | 精子／后代；保留原文隐喻的表达 | 辞书含多义；涉及生育的隐喻不自动等于精液，也不总是细胞名 |
| 愛液 | 润滑液／阴道分泌液／淫液等 | 成人用语中的体液表达；候选语域不同，不能由文学称呼推断具体生理来源或套成医学术语 |
| 月経／生理／排卵／受精／妊娠・孕む | 月经／经期／排卵／受精／怀孕 | 分清阶段和正式、日常表达；`生理`、`孕む` 也有普通或比喻用法 |
| 避妊／コンドーム／性感染症 | 避孕／安全套或避孕套／性传播感染 | 目的、器具和感染概念不同；不因题材把公共卫生说明改成调情口吻 |
| 童貞／処女／初体験／初夜 | 童贞／处女／初次经历／新婚之夜等 | 性经历、身份自述和时间名称分别判断；“初次”具体指何事需看上下文，不由标签推断身体特征或把初夜一律等同初次性行为 |

身体概念可查 [MSD 男性生殖器资料](https://www.msdmanuals.com/ja-jp/home/21-%E7%94%B7%E6%80%A7%E3%81%AE%E5%81%A5%E5%BA%B7%E4%B8%8A%E3%81%AE%E5%95%8F%E9%A1%8C/%E7%94%B7%E6%80%A7%E3%81%AE%E7%94%9F%E6%AE%96%E5%99%A8%E7%B3%BB%E3%81%AE%E7%94%9F%E7%89%A9%E5%AD%A6/%E7%94%B7%E6%80%A7%E7%94%9F%E6%AE%96%E5%99%A8%E3%81%AE%E5%83%8D%E3%81%8D)、[日本产科妇人科学会《HUMAN+》](https://www.jsog.or.jp/public/human_plus_dictionary/book.pdf)和[厚生劳动省性感染症资料](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/kenkou/kekkaku-kansenshou/seikansenshou/)。它们只用于医学概念，不决定对白的中文粗俗度。

俗称与多义的直接依据包括辞书的[おっぱい](https://kotobank.jp/word/%E3%81%8A%E3%81%A4%E3%81%B1%E3%81%84-3208847)、[ちんこ](https://kotobank.jp/word/%E3%81%A1%E3%82%93%E3%81%93-569921)、[ちんぼ](https://kotobank.jp/word/%E3%81%A1%E3%82%93%E3%81%BC-570102)、[まんこ](https://kotobank.jp/word/%E3%81%BE%E3%82%93%E3%81%93-687594)、[尻](https://kotobank.jp/word/%E5%B0%BB-188410)、[穴](https://kotobank.jp/word/%E7%A9%B4-426051)及集英社的[子種](https://imidas.jp/kojiten/detail/W-10-1-623-06.html)。中文候选是翻译判断，不是这些日语释义给出的唯一对译。

## 动作与状态

| 日文 | 中文候选 | 含义、语域与易混点 |
| --- | --- | --- |
| キス／愛撫／前戯／挿入 | 亲吻／爱抚／前戏／插入 | 分清动作与阶段；插入的对象靠上下文，前戏不能泛指所有接触 |
| 正常位／騎乗位／後背位・バック | 正常位或传教士式／骑乘位／后背位或后入式 | 分别涉及正面相对且一方在上、跨坐于另一方上方、从后方的姿势。`バック` 还有返回、后方等普通义；“正常”是术语组成部分。遇到 `正上位` 等作品表记，查说明或画面后确认，不能未经查证当作同义词 |
| 素股 | 素股／股间摩擦 | 辞书含内腿等普通义和成人行为义；后者与插入行为不同，菜单名与解释文字可选不同详略 |
| しゃぶる／しゃぶりつく／舐める | 含吮／吮吸／舔等 | 看宾语、动作方式与持续感；`舐める` 还可能表示轻视，不凭成人题材指定某种行为 |
| オナニー／自慰／手こき | 自慰／手交等 | 自慰强调自我行为，手部刺激还需查施事与对象；不能把两人互动自动写成自慰 |
| フェラ・フェラチオ／クンニ・クンニリングス | 口交／舔阴等 | 以口部刺激的行为，前者指向男性生殖器，后者指向女性生殖器；并列菜单需保留对象差异，不能据此推定施事者的性别 |
| 中出し／外出し | 内射或体内射精／体外射精 | 区别射精位置与动作对象；不能把外出し写成普通外出，也不能由行为名称自动添加怀孕结果 |
| 種付け | 配种／授精／播种等 | 普通义用于繁殖，成人材料可能借作繁殖隐喻。译者词表支持这种用法线索，但作品态度、对象与隐喻强度仍需另判 |
| ローター／バイブ／アナルビーズ | 震动器／跳蛋／按摩棒／肛珠等 | 区分机械词、成人道具与具体外形；`ローター` 的普通辞书义是转子等，不能用它证明道具形状。先看物品图像和说明，再选中文名 |
| ゆっくり動く／激しく動く／ピストン | 缓慢动作／剧烈动作／往复运动等 | 按钮与正文需要各自自然的表达；只有语境明确时才选更具体的动作词，不能全局套成同一句 |
| 勃起／射精／絶頂／オルガズム | 勃起／射精／高潮 | 生理状态、排出过程与感受不同；`絶頂` 也可指一般巅峰，不能假设它与射精同时发生 |
| 潮吹き／潮を吹く | 潮吹／喷液等 | 成人材料中描述喷液现象的用语；普通语境还可能指喷水。与高潮、射精分别理解，不从类型词推断液体成分或生理机制 |
| いく・イく／いかせる | 去、到；达到高潮／让……达到高潮等 | 区分普通趋向、性语境和使役方向；片假名写法不能单独证明义项，确认谁作用于谁 |
| 性欲／精力／エロ技 | 性欲／精力／性技巧等 | 欲望、体力或能力可能是不同属性，按作品机制和语域选词，不合并数值概念 |
| 喘ぎ声 | 喘息声／呻吟声等 | 看呼吸、疲劳、痛苦或性语境；拟声和文字说明的表达方式可不同，不额外增加强度 |
| 開発／調教／射精管理 | 开发／训练／调教／射精控制等 | 普通义、机制名和成人引申义分别处理。查对象、条件和人物态度；没有充分证据时不能为这些标签预设关系、同意程度或具体行为 |

[集英社《しゃぶる》](https://imidas.jp/kojiten/detail/W-12-1-640-06.html)支持其含吮动作范围；辞书的[前戯](https://kotobank.jp/word/%E5%89%8D%E6%88%AF-1691675)和[行く](https://kotobank.jp/word/%E8%A1%8C%E3%81%8F-431393)分别支持特定义项。`開発` 的成人引申义缺少可据以通用定译的直接证据，遇到具体作品仍须查搭配和指向，不将“开发”列为强制答案。
