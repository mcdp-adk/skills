# 日文游戏文本汉化

交付适用于约定游戏版本的汉化补丁，默认采用公开发布所需的质量要求。用户可以明确缩小范围或降低某项要求，记录其影响；局部修订按指定范围处理。

## 调查与范围

读取项目约束，明确原始输入、用户游玩环境、工作材料、独立测试副本和交付物的位置与访问权限。原始输入保持只读。运行前查明存档、设置、日志和缓存的写入范围；无法保证隔离时先解决隔离问题。制作补丁本身不授权安装到游玩环境或改写用户数据。

在允许范围内调查作品、游戏版本、文本来源和使用关系。盘点全部纳入范围的语言内容，包括脚本、界面、代码、资源元数据和动态表达式中的文字。文件扩展名、日文扫描和假名残留只能提供线索。说明图片文字等排除项的实际影响，默认保留原图。

查明各显示位置使用的字体、中文支持和所需来源；玩家可输入中文时，也要考虑输入字符。根据实际用途决定字体与接入方案。

核实本次会话能否处理文件、执行脚本、使用子 agent 和操作目标游戏界面；工具可按需发现时，先查找再判断缺失。确实缺少必要能力，就说明影响哪项验收、如何补齐及哪些工作仍可继续。检查未实现或工具故障由 agent 补做、修复，补丁错误由 agent 定位处理，不能统称为能力缺失。

向用户说明调查结果、推荐方案，以及影响范围、资源准备、使用方式或质量的取舍，再请用户决定仍未明确的部分。能查清的事实和实施细节由 agent 负责，不要求用户选择检查算法、记录格式或固定流程。新发现改变上述取舍时再解释，不自行降低验收要求。

## 原文、译文与术语

保留指定版本的原文基准，用原文及使用关系判断含义。翻译单元保留来源定位和足够上下文，可以跨越行或字符串片段；对白需要前后文，短文本需要所属界面或剧情，拼接文本需要组合关系。

语言内容与运行数据可能共用同一字符串。路径、标签、内部 ID 等值先查用途，再决定能否改动；确需适配时只作必要改动，保住资源与控制关系。遇到陌生格式，先用少量代表性内容确认提取、回填和读取方式可行，再扩大处理规模。

译文基准保存当前确认的完整译文；交付资源和需要同步的派生显示数据从这里生成或更新。项目术语表只维护作品内约定，记录候选与定译的区别及必要出处，不另建竞争的决定来源。

全量登记人物名和专有名词，包括配角、别名、昵称、职业及有指代作用的匿名人物称谓；其他词按辨义和统一表达的需要纳入。新增或改译后，更新受影响的译文并回查。既有中文或术语约定与原文冲突时，回到原文查证，再同步修订约定与译文。

## 翻译与审校

由 agent 直接阅读原文和上下文翻译。贴合原意优先，保留人物关系、视点、语气、语域、信息强度和不确定程度，再使中文准确、通顺、一致。复用译文也要核对语境；动态片段按完整表达检查，避免无条件的全局词对词替换。

- 遇到省略、授受、使役、否定、情态、敬语、拟声拟态或双关，读取[翻译与审校方法](references/translation.md)中的对应部分。
- 翻译或审校选项、按钮、标题、称号及动态组合时，读取同一参考的短文本与组合部分。短文本要结合实际用途、同组选项或相邻标签判断，检查中文搭配、动作对象、态度与承诺程度；标题和称号保留命名意图及作品风格。改得简洁自然后回对原文，不增加结果说明或剧透。
- 遇到称谓、多义词、成人题材词汇或语域选择，查[术语辨义](references/terminology.md)。中文候选辅助判断，不构成替换表。查清具体指代后，仍须保留原文的明确或委婉程度。

主 agent 确认有充分依据的译法。重要且查证仍不能解决、会影响人物设定、全篇风格或大量译文的取舍，才交用户决定。

优先让子 agent 承担批量翻译和审校。按连贯剧情或功能划分责任范围，提供原文、必要上下文和当前术语信息，避免并发覆盖。主 agent 调度、合并、处理冲突、同步术语变化并抽查交界处；代理数量和批次大小按工作量安排。

全部纳入内容都要对照原文、译文和上下文作双语审校，再按剧情或功能连读中文。审校者独立判断初译，修改应有原意、中文表达或项目约定依据，改后重新核对原文。疑义保留定位并继续查证，不能以主 agent 抽查代替全量审校。

## 验证与交付

设计检查、处理字体或持久化状态问题、准备交付时，读取[验证与交付](references/verification.md)。根据实际改动做适用的程序检查，并通过适量 Computer Use 观察游戏显示和真实流程。运行抽查不缩小文本翻译与审校的范围。

将实际候选补丁应用到由原始输入建立的独立测试副本，检查回填、资源、显示和相关运行状态。变更后复查受影响结果；区分原版缺陷、汉化引入问题与存档、设置等持久化状态的影响。旧存档兼容或迁移按实际需要、项目范围和授权决定。

交付补丁，写清适用版本、应用方式、实际检查对象与结果、剩余限制和未验证部分。保留必要译文、术语和处理记录，便于继续修订。结论与证据范围一致：扫描为零、工具成功、哈希相同或少量截图均不能证明完整质量。
