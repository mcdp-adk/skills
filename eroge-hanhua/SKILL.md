# 日文 R18 游戏汉化

默认按公开发布的质量要求交付适用于约定游戏版本的文本汉化补丁。纳入范围包括普通剧情、成人内容、界面和动态文字，以及载入、显示译文所需的适配；图片重绘和配音默认不纳入。用户可以缩小范围或降低具体要求，说明并记录相应影响。局部修订沿用项目约定，处理指定内容及其影响。

## 调查并确认安排

读取项目约束，核实原始游戏的位置、版本和访问权限。原始输入保持只读，游玩环境按用户授权访问。调查需要解包、生成文件或建立测试副本时，先确定写入位置：沿用已有授权；位置未定，就提出具体目录及用途，请用户确认后再写入。等待期间继续不依赖该决定的已授权工作。

调查文本来源、使用关系、回填方式和主要限制，查明各显示位置的字体及中文支持，包括玩家输入中文的需求。启动游戏前，读取[补丁验证](references/verification.md)的“隔离与运行状态”一节，确认存档、设置、日志和缓存使用独立的测试位置。

向用户讲解调查结果和推荐方案：哪些内容会汉化，哪些图片文字等内容会保留，需要补充什么资源及其用途，补丁如何应用，已知限制怎样影响游玩。列明下列对象的实际位置和用途：

| 对象 | 用途与边界 |
| --- | --- |
| 原始输入 | 指定版本的游戏及原始资源，只读保留 |
| 游玩环境 | 用户游玩的游戏目录，以及存档、设置等用户数据 |
| 工作材料 | 提取文件、译文、术语表、加工文件、工具和处理记录 |
| 独立测试副本 | 从原始输入建立，应用候选补丁，使用独立运行数据 |
| 交付物 | 最终补丁及使用说明 |

与用户确定文本范围、资源准备、交付内容、应用方式和质量要求。已有明确指令直接沿用；尚未明确的取舍，先解释影响再请用户决定。事实调查、工具选择和检查安排由 agent 负责。把约定保存在项目记录中；新发现改变约定时，说明变化并处理新的待决事项。制作补丁不授权安装到游玩环境或改写用户存档。

按任务需要核实文件处理、脚本执行、子 agent 和游戏界面操作能力；支持按需发现工具时先查找。确实缺少必要能力，说明受影响的验收、补齐方式及仍可继续的工作。尚未实现的检查由 agent 补做，工具故障和补丁错误分别修复，不据此自行降低质量要求。

## 整理文本与翻译依据

按用途盘点全部纳入内容，保留来源定位和处理结果。**语言内容**向玩家传达剧情、人物表达或操作信息；**运行数据**承担执行控制、资源定位或状态标识。两者可能共用字符串，改动前须查清依赖。脚本、代码、界面、资源元数据和动态表达式都可能含文字，文件类型和日文扫描只作查找线索。

以足够上下文划分**翻译单元**，允许跨行或跨字符串。对白需要前后文与人物关系，短文本需要显示用途，拼接文本需要组合条件。遇到陌生格式，先用少量代表内容验证提取、回填和读取可行，再扩大处理规模；涉及运行数据时只作必要的最小适配。

| 依据 | 维护内容与作用 |
| --- | --- |
| 原文基准 | 指定版本的原文、资源及使用关系，用于判义 |
| 译文基准 | 当前确认的完整译文，是交付资源和需同步的派生显示数据的唯一译文维护来源 |
| 项目术语表 | 作品内人物名、专名及需统一表达的约定，区分候选与定译，保留必要出处 |

全量登记人物名和专有名词，包括配角、别名、昵称、职业及有指代作用的匿名人物称谓；其他词按辨义和统一表达的需要纳入。翻译与审校共用项目术语表。新增或改译后同步译文，回查受影响位置；已有中文或约定与原文冲突时，回到原文查证并修订。

## 翻译与审校

由 agent 直接阅读原文和上下文翻译。贴合原意优先，保留人物关系、视点、语气、语域、信息强度与不确定程度，再使中文准确、通顺、一致。复用译文逐处核对语境，动态片段按完整表达判断。

- 处理日语理解难点、选项和标题等短文本、动态组合或双语审校时，读取[翻译与审校](references/translation.md)相应部分。选项、按钮、标题和称号须重点审校。
- 判断称谓、多义词、成人题材词汇及语域时，查[术语辨义](references/terminology.md)。通用参考提供词义和候选，作品定译依据原文与上下文；查明对象后，译文仍保留原文的明确或委婉程度。

优先由子 agent 承担批量翻译和审校。按连贯剧情或功能分工，提供原文、必要上下文及当前术语信息，分开写入范围。主 agent 调度、合并、处理冲突、同步约定并抽查交界处。有充分依据的译法由主 agent 确认；重要且查证仍不能解决、会影响人物设定、全篇风格或大量译文的取舍，附依据和候选交用户决定。

全部纳入内容均须对照原文和上下文审校，再按剧情或功能连读中文；主 agent 的抽查不替代全量审校。审校者独立判断含义，修改须有原意、中文表达或项目约定依据，改后回对原文。修正写入译文基准，疑义保留定位并继续查证。

## 验证并交付补丁

设计检查、适配字体、处理持久化状态或准备交付时，读取[补丁验证](references/verification.md)相应部分。从译文基准回填并打包，将实际候选补丁应用到独立测试副本。完成适用的程序检查，结合适量 Computer Use 观察真实显示和流程；文本审校范围与运行取样范围分别记录。

区分原版缺陷、汉化错误和运行状态影响，修复后复查受影响部分。旧档兼容或迁移按实际需要、项目范围及授权处理。核对交付物与测试对象，结论限定在证据支持的范围内，写明剩余问题和未验证部分。

在约定位置交付补丁及说明，列明适用版本、应用方式、实际检查结果和兼容限制。保留可继续维护的译文、术语和处理记录。交付内容与约定不符时，先向用户解释差异并确定处理方式。
